# TRaVeLiNG Tools (Web)

旅行向けの小ツールをまとめたWebアプリです。

## 公開ページ

https://hbkrkzk.github.io/TRaVeLiNG-Tools-Web/

## 主な機能

1. Skyscanner Link
- Skyscannerの検索URLをアフィリエイトURLに変換
- 短縮URL（`skyscanner.app.link`）の展開に対応
- 短縮URL生成とシェア文面の自動生成

2. Boarding Barcode
- 搭乗券情報から IATA 文字列を生成
- Aztec / PDF417 バーコードを生成

3. FIRE Simulator
- 資産推移のシミュレーション
- リタイア時資産と資産寿命の可視化
